Understanding Risk and Return - Simple Explanation

The Big Picture: Risk vs. Return

Imagine you're deciding where to put your money:

Option Potential Return Risk
Savings Account Low (1-2%) Very Low
Government Bonds Low-Medium (3-5%) Low
Stocks Medium-High (7-10%) Medium-High
Cryptocurrency Very High (100%+) Very High

The Golden Rule: Higher potential return = Higher risk

This is called the risk-return trade-off. You can't get high returns without accepting the possibility of losses.

---

What is Return?

Return = The financial reward from an investment.

Simple Example

You buy a stock for $100. One year later, it's worth $110.

\text{Return} = \frac{110 - 100}{100} = 10\%

Types of Return

Type What It Means
Realized Return Money you've already made
Unrealized Return Profit on paper (haven't sold yet)
Price Return Just the price change
Total Return Price change + Dividends

Total Return Formula

R = \frac{S_t + D_t - S_{t-1}}{S_{t-1}}

Where:

· S_t = Price at end
· S_{t-1} = Price at start
· D_t = Dividends received

Why total return matters: A stock might stay flat in price but pay 5% dividends. You still made money!

---

The 1+R Format

Why use 1+R? It makes compounding easy.

Normal return: R = 10%
1+R format: 1 + 0.10 = 1.10

Multiperiod Returns (Compounding)

If you earn 10% in year 1 and 5% in year 2:

Wrong way: 10% + 5% = 15%
Right way: (1.10 × 1.05) - 1 = 15.5%

The extra 0.5% comes from compounding — earning returns on your returns.

Example: Two-Period Return

Period Return 1+R
Year 1 10% 1.10
Year 2 -2% 0.98

\text{Two-year return} = (1.10 \times 0.98) - 1 = 7.8\%

Key insight: You can't just add returns. You must multiply.

---

Terminal Return

Terminal return = Total return from start to finish.

R_{0,T} = \frac{S_T}{S_0} - 1

Example: Buy at $100, sell at $150 after 3 years.

\text{Terminal return} = \frac{150}{100} - 1 = 50\%

Limitation: Ignores what happened in between. A bumpy ride and a smooth ride look the same.

---

Annualizing Returns

Problem: How do you compare a monthly return of 1% with a yearly return of 15%?

Solution: Convert everything to annual terms.

Formula

\text{Annualized Return} = (1 + R_{\text{period}})^n - 1

Where n = number of periods per year.

Examples

Period Return Periods/Year Annualized
Daily 0.01% 252 2.55%
Monthly 1% 12 12.68%
Quarterly 5% 4 21.55%

Why not just multiply? Compounding! 1% monthly ≠ 12% yearly (it's 12.68%).

---

What is Risk?

Risk = Uncertainty of returns. How much do returns bounce around?

Visual Example

Two assets with same average return (16%):

Asset 1: 5%, 30%, -10%, 35%, 20%
Asset 2: 50%, -20%, 30%, 50%, -30%

Asset 2 is more volatile — it swings more wildly.

Measuring Risk: Variance and Standard Deviation

Variance = Average of squared deviations from the mean.

\text{Variance} = \frac{\sum (R_i - \bar{R})^2}{N}

Standard Deviation = Square root of variance.

\text{Volatility} = \sqrt{\text{Variance}}

Why standard deviation? It's in the same units as returns (%), making it easier to interpret.

Step-by-Step Calculation

1. Calculate mean return
2. Subtract mean from each return (deviation)
3. Square each deviation
4. Average the squared deviations (variance)
5. Take square root (standard deviation)

Example

Return Deviation Squared
5% -11% 1.21%
30% 14% 1.96%
-10% -26% 6.76%
35% 19% 3.61%
20% 4% 0.16%

Mean = 16%
Variance = (1.21 + 1.96 + 6.76 + 3.61 + 0.16) / 5 = 2.74%
Volatility = √2.74% = 16.55%

---

Annualizing Volatility

Formula:

\text{Annualized Volatility} = \sigma_{\text{period}} \times \sqrt{n}

Where n = periods per year.

Examples

Period Volatility n Annualized
Daily 0.1% 252 1.59%
Monthly 5% 12 17.32%
Quarterly 10% 4 20%

Key insight: Volatility grows with the square root of time, not linearly.

Why? Random movements partially cancel out over longer periods.

---

The Sharpe Ratio: Combining Risk and Return

Problem: Asset A returns 5% with 20% volatility. Asset B returns 10% with 50% volatility. Which is better?

Solution: Risk-adjusted return — the Sharpe Ratio.

Formula

\text{Sharpe Ratio} = \frac{R_p - R_f}{\sigma_p}

Where:

· R_p = Portfolio return
· R_f = Risk-free rate
· σ_p = Portfolio volatility

Interpretation

· Higher Sharpe = Better risk-adjusted performance
· Measures return per unit of risk
· Subtracts risk-free rate to isolate excess return

Example

 Portfolio 1 Portfolio 2
Return 5% 10%
Volatility 20% 50%
Risk-free rate 3% 3%
Excess Return 2% 7%
Sharpe Ratio 0.10 0.14

Portfolio 2 wins on a risk-adjusted basis!

The Four Quadrants of Risk-Return

```
High Return
    |
    |  Low Risk,     |  High Risk,
    |  High Return   |  High Return
    |  (Rare)        |  (Stocks, Derivatives)
    |
----+----------------+------------------
    |
    |  Low Risk,     |  High Risk,
    |  Low Return    |  Low Return
    |  (Bonds, T-Bills)| (Rare, Irrational)
    |
Low Return
```

· Bottom-Left: Safe but boring (bonds, savings)
· Top-Right: Risky but rewarding (stocks, crypto)
· Top-Left: Too good to be true (rare, often a trap)
· Bottom-Right: Irrational (why take risk for no reward?)

Practical Calculations with Python

Downloading Stock Data

```python
import yfinance as yf
prices = yf.download(["AAPL", "GOOG"], start="2023-01-01")
prices = prices['Adj Close']
```

Calculating Returns

```python
returns = prices.pct_change().dropna()
```

Calculating Volatility

```python
daily_vol = returns.std()
annualized_vol = daily_vol * (252 ** 0.5)
```

Calculating Annualized Return

```python
# Geometric mean approach
daily_return = (returns + 1).prod() ** (1/len(returns)) - 1
annualized_return = (daily_return + 1) ** 252 - 1
```

Calculating Sharpe Ratio

```python
risk_free = 0.03
excess_return = annualized_return - risk_free
sharpe = excess_return / annualized_vol
```

Common Mistakes to Avoid

Mistake Why It's Wrong Correct Approach
Adding returns Ignores compounding Multiply (1+R) terms
Multiplying volatility by n Volatility grows with √n Multiply by √n
Using arithmetic mean for multiperiod Overstates returns Use geometric mean
Ignoring dividends Understates total return Include dividends
Comparing different time periods directly Not standardized Annualize first

---

The Big Picture

Return = How much money you make
Risk = How much it bounces around

Key Principles:

1. Risk-return trade-off: Higher returns require accepting higher risk
2. Compounding matters: Returns multiply, not add
3. Annualize for comparison: Standardize different time periods
4. Risk-adjusted metrics: Sharpe ratio helps compare investments fairly
5. Diversification: Spreading investments reduces risk

The Goal: Maximize return for a given level of risk, or minimize risk for a given level of return.
