Trend-Following Strategy - Simple Explanation

What is Trend Following?

Imagine you're watching a ball roll down a hill. You don't know exactly where it will stop, but you know it's probably going to keep rolling down for a while.

Trend following works the same way with prices:

· If prices have been going up, bet they'll keep going up
· If prices have been going down, bet they'll keep going down

The core idea: "The trend is your friend."

Simple Example

Price Pattern Trend Follower's Action
Stock rising from $100 → $110 → $120 Buy (expecting it to keep rising)
Stock falling from $120 → $110 → $100 Sell/Short (expecting it to keep falling)

Why it can work: Markets often move in sustained directions due to momentum, investor psychology, and economic cycles.

The risk: Trends can reverse suddenly. That's why trend followers always use stop-loss orders to limit losses.

Log Returns: A Better Way to Measure Returns

Why Use Log Returns?

Problem with simple returns:

· If a stock goes up 50% then down 50%, you might think you're back to even. But you're not!
· $100 → $150 (up 50%) → $75 (down 50%). You lost 25%!

Solution: Log returns (also called continuously compounded returns)

The Formula

\text{Log Return} = \ln\left(\frac{S_{t+1}}{S_t}\right)

Where:

· S_t = Price today
· S_{t+1} = Price tomorrow
· ln = Natural logarithm

Key Properties of Log Returns

Property What It Means Why It's Useful
Time Additive Total log return = Sum of daily log returns Easy to calculate multi-period returns
Symmetric +10% then -10% = 0% total More intuitive
Closer to Normal Better for statistical models Most finance models assume normality
Continuous Compounding Represents continuously compounded returns Used in options pricing

Example: Symmetry

Simple returns:

· Price: $100 → $108 → $100
· Day 1: +8%
· Day 2: -7.4%
· Sum: +0.6% (not zero!)

Log returns:

· Day 1: ln(108/100) = 7.7%
· Day 2: ln(100/108) = -7.7%
· Sum: 0% (perfectly symmetric!)

Example: Time Additivity

Calculating 3-day return:

Simple returns: Must multiply (1+R1)(1+R2)(1+R3) - 1

Log returns: Just add! R1 + R2 + R3

```
Day 1: +2%
Day 2: -1%
Day 3: +3%

Simple: (1.02)(0.99)(1.03) - 1 = 4.03%
Log: 2% + (-1%) + 3% = 4% (approximately)
```

Moving Averages: Smoothing Out the Noise

The Problem

Daily stock prices are noisy — they jump around randomly. It's hard to see the underlying trend.

The Solution

Moving Average (MA): Average the last N prices to smooth out the noise.

Simple Moving Average (SMA)

\text{SMA}_t = \frac{S_t + S_{t-1} + ... + S_{t-M+1}}{M}

Example: 3-day SMA

Day Price 3-day SMA
1 $100 —
2 $102 —
3 $104 $102.00
4 $103 $103.00
5 $105 $104.00

How it works:

· Day 3 SMA = (100 + 102 + 104) / 3 = 102
· Day 4 SMA = (102 + 104 + 103) / 3 = 103
· The window "rolls" forward, dropping the oldest price

Choosing M (window size):

· Small M (e.g., 3): More responsive, but noisier
· Large M (e.g., 200): Smoother, but slower to react

Exponential Moving Average (EMA)

Problem with SMA: Treats all prices equally. A price from 20 days ago matters as much as yesterday's price.

Solution: EMA gives more weight to recent prices.

\text{EMA}_t = \alpha \times S_t + (1-\alpha) \times \text{EMA}_{t-1}

Where α (alpha) is the smoothing factor (0 to 1).

How it works:

· High α (e.g., 0.5): Reacts quickly to new prices
· Low α (e.g., 0.1): Smoother, more weight on history

Comparison:

Feature SMA EMA
Weighting Equal for all More for recent
Reactivity Slower Faster
False signals Fewer More
Best for Long-term trends Short-term trading

The Trend-Following Strategy Using Moving Averages

The Crossover Rule

Use two moving averages:

· Short-term MA (fast): e.g., 3-day
· Long-term MA (slow): e.g., 20-day

Trading signals:

Condition Signal Action
Short MA crosses above Long MA Buy Go long
Short MA crosses below Long MA Sell Go short

Why it works:

· When short MA > long MA, recent prices are higher than average → uptrend
· When short MA < long MA, recent prices are lower than average → downtrend

Visual Example

```
Price
  |     Short MA crosses above → BUY
  |         /\
  |        /  \     Short MA crosses below → SELL

  |    /          \ /
  |   /            v
```

The Golden Cross and Death Cross

Pattern What Happens Signal
Golden Cross 50-day MA crosses above 200-day MA Bullish (buy)
Death Cross 50-day MA crosses below 200-day MA Bearish (sell)

Implementing the Strategy in Python

Step 1: Download Data

```python
import yfinance as yf
df = yf.download("AAPL", start="2022-01-01", end="2023-01-01")
```

Step 2: Calculate Moving Averages

```python
# Simple Moving Averages
df['SMA-3'] = df['Adj Close'].rolling(3).mean()
df['SMA-20'] = df['Adj Close'].rolling(20).mean()

# Exponential Moving Averages
df['EMA-0.1'] = df['Adj Close'].ewm(alpha=0.1, adjust=False).mean()
df['EMA-0.5'] = df['Adj Close'].ewm(alpha=0.5, adjust=False).mean()
```

Step 3: Shift to Avoid Look-Ahead Bias

Critical rule: You can only use yesterday's information to make today's decision.

```python
# Shift by 1 day so today uses yesterday's MA
df['SMA-3'] = df['SMA-3'].shift(1)
df['SMA-20'] = df['SMA-20'].shift(1)
```

Why this matters: If you use today's closing price to decide today's trade, you're cheating (look-ahead bias). In reality, you don't know today's close until the market closes.

Step 4: Generate Signals

```python
import numpy as np

# Buy when short MA > long MA, Sell when short MA < long MA
df['signal'] = np.where(df['SMA-3'] > df['SMA-20'], 1, 0)
df['signal'] = np.where(df['SMA-3'] < df['SMA-20'], -1, df['signal'])

# Remove rows with NaN
df.dropna(inplace=True)
```

Signal meanings:

· +1: Go long (buy)
· -1: Go short (sell)
· 0: No position

Step 5: Calculate Returns

```python
# Log return of buy-and-hold
df['log_return_buy_n_hold'] = np.log(df['Adj Close']).diff()

# Log return of trend-following strategy
df['log_return_trend_follow'] = df['signal'] * df['log_return_buy_n_hold']
```

How it works:

Signal Log Return Strategy Return Meaning
+1 +2% +2% Long and price up → profit
+1 -1% -1% Long and price down → loss
-1 +2% -2% Short and price up → loss
-1 -1% +1% Short and price down → profit

Step 6: Calculate Cumulative Returns

```python
# Buy-and-hold cumulative return
buy_hold_cum = np.exp(df['log_return_buy_n_hold']).cumprod()

# Trend-following cumulative return
trend_cum = np.exp(df['log_return_trend_follow']).cumprod()

# Terminal returns
buy_hold_terminal = buy_hold_cum[-1] - 1
trend_terminal = trend_cum[-1] - 1
```

Technical Indicators: Beyond Moving Averages

What it measures: Speed and magnitude of price changes (0-100)

RSI Level Interpretation Action
Above 70 Overbought Consider selling
Below 30 Oversold Consider buying

Moving Average Convergence Divergence (MACD)

What it measures: Relationship between two EMAs (12-day and 26-day)

Signal Interpretation
MACD crosses above signal line Bullish (buy)
MACD crosses below signal line Bearish (sell)
MACD above zero Upward momentum
MACD below zero Downward momentum

Bollinger Bands

What they measure: Volatility (price standard deviation)

Pattern Interpretation
Price touches upper band Overbought
Price touches lower band Oversold
Bands widen High volatility

Using too many indicators Overfitting Keep it simple
No stop-loss Unlimited risk Always use stop-loss

The Big Picture

Trend following in one sentence: "Identify the direction of the market and bet it continues."

Key principles:

1. Trends exist — Prices move in sustained directions
2. Momentum persists — What's moving tends to keep moving
3. Cut losses short — Use stop-losses
4. Let profits run — Don't exit too early
5. Discipline over emotion — Follow the rules

The moving average crossover strategy:

· Simple to understand and implement
· Works across many markets
· A good baseline for comparing other strategies
· Not perfect — no strategy always works

Remember: Trend following is about catching big moves, not predicting every wiggle. You'll have many small losses, but a few large wins can make the strategy profitable overall.
